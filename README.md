**Среда моделирования:** Виртуальный стенд Proxmox Virtual Environment 8.2

## 🗺️ 1. Архитектура и топология сети

Лабораторный комплекс моделирует распределенную сеть предприятия с центральным офисом (**HQ**), удаленным филиалом (**BR**) и пограничной маршрутизацией через интернет-провайдера (**ISP**):

1. **ISP (Провайдер):** ALT Linux Server. Осуществляет маршрутизацию внешнего трафика, трансляцию сетевых адресов (NAT), службу точного времени NTP (Stratum 5) и обратное проксирование веб-ресурсов (Nginx Reverse Proxy).
2. **HQ-RTR (Маршрутизатор Центра):** EcoRouter. Агрегирует VLAN 100/200/999, обеспечивает динамическую маршрутизацию OSPF (Area 0), трансляцию NAT и терминацию GRE-туннеля до филиала.
3. **BR-RTR (Маршрутизатор Филиала):** EcoRouter. Обеспечивает связность с центральным офисом через туннель GRE, стыкуется с пограничным шлюзом безопасности Ideco NGFW.
4. **BR-FW (Межсетевой экран):** Ideco NGFW. Контроль доступа, фильтрация прикладного трафика, защита сетевого периметра филиала.
5. **HQ-SRV (Сервер Центра):** ALT Linux. Служба доменных имен DNS (BIND9), дисковый массив RAID 0, сетевое файловое хранилище NFS, защищенный веб-сервер и удаленный доступ SSH на нестандартном порту 2027.
6. **BR-SRV (Контроллер Домена):** ALT Linux. Контроллер домена Samba Active Directory (u-team.irpo), автоматизированный импорт пользователей, службы мониторинга и резервного копирования.
7. **HQ-CLI (Клиентская станция):** ALT Linux Workstation. Рабочая станция сотрудника, ввод в домен, тестирование доступности сервисов и сквозной аутентификации Kerberos.

## 🛠️ 3. Структура каталога конфигураций (configs/)

Все сценарии конфигурации разбиты по лабораторным этапам:

### Модуль 1: Базовая связность и сетевая маршрутизация
- [configs/lab1_01_isp_gateway.sh](configs/lab1_01_isp_gateway.sh) — Базовая адресация ALT Linux, включение IP-форвардинга и masquerade iptables.
- [configs/lab1_02_hq_router.txt](configs/lab1_02_hq_router.txt) — Настройка саб-интерфейсов VLAN, GRE-туннеля, пулов DHCP и процесса OSPF.
- [configs/lab1_03_br_router.txt](configs/lab1_03_br_router.txt) — Настройка маршрутизатора филиала, OSPF Area 0, связность с Ideco NGFW.
- [configs/lab1_04_br_firewall_init.txt](configs/lab1_04_br_firewall_init.txt) — Первичные параметры консоли шлюза Ideco NGFW.
- [configs/lab1_05_hq_server.sh](configs/lab1_05_hq_server.sh) — Статическая адресация, DNS BIND (u-team.irpo), реверсные зоны, SSH на порту 2027.
- [configs/lab1_06_br_server.sh](configs/lab1_06_br_server.sh) — Сетевые интерфейсы сервера филиала и проверка сквозной связности.
- [configs/lab1_07_hq_client.sh](configs/lab1_07_hq_client.sh) — Настройка сетевого клиента и проверка шлюзов.

### Модуль 2: Корпоративные сервисы и служба каталогов
- [configs/lab2_01_isp_ntp.sh](configs/lab2_01_isp_ntp.sh) — Синхронизация времени Chrony NTP сервер Stratum 5.
- [configs/lab2_02_hq_services.sh](configs/lab2_02_hq_services.sh) — Создание программного массива RAID 0, экспорт NFS, LAMP стек, SRV-записи DNS.
- [configs/lab2_03_routers_nat.txt](configs/lab2_03_routers_nat.txt) — Проброс портов и списки доступа на маршрутизаторах.
- [configs/lab2_04_br_domain_services.sh](configs/lab2_04_br_domain_services.sh) — Развертывание контроллера домена Samba AD DC, Zabbix Server.
- [configs/lab2_05_hq_client_join.sh](configs/lab2_05_hq_client_join.sh) — Интеграция клиента ALT Linux Workstation в домен u-team.irpo.

### Модуль 3: Безопасность периметра, аудит и отказоустойчивость
- [configs/lab3_01_br_user_import.sh](configs/lab3_01_br_user_import.sh) — Автоматический парсинг файла учетных записей Users.csv и создание подразделений OU.
- [configs/lab3_02_isp_reverse_proxy.sh](configs/lab3_02_isp_reverse_proxy.sh) — Nginx Reverse Proxy, SSL/TLS сертификаты, базовая аутентификация.
- [configs/lab3_03_hq_security_audit.sh](configs/lab3_03_hq_security_audit.sh) — Политики паролей, ротация логов, аудит входа, WireGuard VPN.
