1. ISP (ALT Linux — Пограничный шлюз провайдера)

IP: ens18 (DHCP WAN) | ens19 (172.16.1.1/28 к HQ) | ens20 (172.16.2.1/28 к BR)
Методическое обоснование:

Шлюз провайдера объединяет филиалы через внешнюю IP-сеть, обеспечивает трансляцию сетевых адресов (NAT Masquerade) и маршрутизацию пакетов с включенным форвардингом ядра Linux.

Критерии оценки КИМ (ИРПО):

Корректность IP-адресации, включение net.ipv4.ip_forward=1, трансляция NAT во внешнюю сеть ens18.

hostnamectl set-hostname isp
timedatectl set-timezone Europe/Moscow
mkdir -p /etc/net/ifaces/ens19
mkdir -p /etc/net/ifaces/ens20

cat << 'EOF' > /etc/net/ifaces/ens18/options
TYPE=eth
BOOTPROTO=dhcp
DISABLED=no
EOF

cat << 'EOF' > /etc/net/ifaces/ens19/options
TYPE=eth
BOOTPROTO=static
DISABLED=no
EOF

cp /etc/net/ifaces/ens19/options /etc/net/ifaces/ens20/options
echo "172.16.1.1/28" > /etc/net/ifaces/ens19/ipv4address
echo "172.16.2.1/28" > /etc/net/ifaces/ens20/ipv4address

cat << 'EOF' >> /etc/net/sysctl.conf
net.ipv4.ip_forward = 1
EOF

sysctl -p /etc/net/sysctl.conf
systemctl restart network

apt-get update && apt-get install -y iptables tzdata
iptables -t nat -A POSTROUTING -s 172.16.1.0/28 -o ens18 -j MASQUERADE
iptables -t nat -A POSTROUTING -s 172.16.2.0/28 -o ens18 -j MASQUERADE
iptables-save > /etc/sysconfig/iptables
systemctl enable --now iptables
ip a
🔍 Команды экспертной верификации: ip a (наличие 172.16.1.1 и 172.16.2.1) • sysctl net.ipv4.ip_forward (=1) • iptables -t nat -L -n -v (MASQUERADE)

Модуль 3: Информационная безопасность, системный аудит и отказоустойчивость

1. BR-SRV (Автоматизированный импорт пользователей из Users.csv)

Парсинг CSV-файла, создание организационных подразделений (OU) и учетных записей 
mkdir -p /mnt/add
mount -o ro /dev/sr1 /mnt/add 2>/dev/null || true

cat << 'EOF' > /root/import.sh
#!/bin/bash
csv=${1:-/mnt/add/Users.csv}
tail -n +2 "$csv" | tr -d '
' > /tmp/users.csv
cut -d';' -f5 /tmp/users.csv | sort -u | while read -r ou; do
  samba-tool ou add "OU=$ou" 2>/dev/null || true
done
while IFS=';' read -r user name surname pass ou; do
  samba-tool user add "$user" "$pass" --userou="OU=$ou" --given-name="$name" --surname="$surname" 2>/dev/null || true
done < /tmp/users.csv
EOF
chmod +x /root/import.sh
/root/import.sh
